# dsh-turn-notify · 完成通知

[English](./README.md) | 简体中文

在 DeepSeek's Harness（DSH）回合结束或等待确认时，通过系统通知、应用内提示和可选提示音提醒你。点击通知可以跳转到对应会话。

本文描述当前源码。市场安装的版本由索引中的 commit 决定；尚未发布的修改见 [CHANGELOG](./CHANGELOG.md)。

## 当前本地待测版本

当前源码版本为 **1.0.1**，暂未发布。兼容声明先限定 DSH `0.2.2-rc.2` 和 `0.2.2-rc.3`；这是本轮试用范围，不代表所有系统／浏览器均已人工验收。已链接本地源码时，重新加载或重启 DSH 即可试用。公开索引仍指向旧版，试用期间不要用市场旧版覆盖本地链接。详见 [试用与发布清单](./RELEASE.md)。

## 安装与首次使用

1. 打开 DSH 的 **Plugins／插件** 页面，在 **Experimental plugins／实验性插件** 中启用 **Custom plugin indexes／自定义插件索引**。
2. 打开新出现的 **Discover／发现** 标签，选择 **Add index source／添加索引源**，添加：

   ```text
   https://cdn.jsdelivr.net/gh/Ly007-dotcom/dsh-turn-notify@main/market-index.json
   ```

3. 搜索 `dsh-turn-notify`，检查版本和来源后点击安装、确认。
4. 回到 **Installed／已安装**，确认插件已启用；按 DSH 提示重新加载或重启。
5. 打开 **Settings → General／设置 → 通用**，找到 **完成通知**。总开关默认开启，控制系统通知、应用内提示和提示音。下面的 **提示音** 开关单独决定是否播放声音。
6. 首次使用浏览器时，点击首次提示中的开启按钮，或设置里的 **允许系统通知**，在浏览器弹窗中授权。拒绝系统通知权限不会关闭应用内提醒，也不会妨碍总开关关闭所有提醒。
7. 点击 **发送测试通知**，分别检查应用内卡片、系统横幅和声音。系统横幅还受操作系统通知设置和勿扰模式影响；看到测试卡片不代表系统横幅已经送达。

DSH 不预置此索引。发布 GitHub 仓库不会自动让所有用户在 Discover 中找到它。索引维护见 [MARKET-INDEX.md](./MARKET-INDEX.md)，机制见 [DSH 官方说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/plugin-market.md)。

### 从源码安装

已安装 DSH CLI 和 pnpm 时，可执行以下命令，将 `<profile>` 替换为实际配置名称，然后重启对应 profile：

```bash
git clone https://github.com/Ly007-dotcom/dsh-turn-notify.git
cd dsh-turn-notify
dsh plugin --profile <profile> add .
```

也可通过桌面端插件管理器安装本地 checkout。本插件不需要构建步骤。

## 设置与行为

- **总开关**：默认开启，与系统通知权限独立。关闭后停止三种提醒，清除当前应用内卡片并停止提示音。操作系统通知中心中的历史通知需在系统中清除。
- **提示音**：默认开启，仅在总开关也开启时生效。
- **系统通知权限**：由浏览器单独管理；未授权、拒绝或不支持时，应用内卡片及浏览器允许播放的提示音仍可工作。
- 回合停止后等待约 **1.8 秒**；若立即继续运行则取消完成提醒。等待确认立即处理，不额外发送完成提醒。
- 子代理和空白会话不提醒。“回合已结束”表示观察到停止运行，并不保证任务成功；错误和手动停止也可能触发提醒。
- 偏好在同源、同存储分区的窗口之间同步。写入存储失败时，当前页面仍遵守开关选择，但刷新后可能恢复默认值。

## 使用边界与去重范围

- 需要桌面客户端的应用界面或 Web UI 保持运行并连接 DSH。关闭窗口、退出客户端、断网、系统休眠或后台页面冻结时，不保证及时提醒。重新打开页面不会补发历史完成事件。
- 本插件在客户端运行，不提供纯 CLI、TUI、headless 或离线推送。
- 多窗口通过 **IndexedDB 原子事务**竞争同一事件，记录保留 **24 小时**。完成事件使用会话 ID 和 DSH 的 `updatedAt`，确认事件使用请求 key；需要各窗口观察到相同的事件标识。
- 去重仅覆盖**同一来源（协议、域名、端口）且共享存储分区**的窗口。不同浏览器、普通与隐私窗口、不同设备、桌面客户端与 Web UI 之间分别通知，设置也可能独立。
- 24 小时后旧记录不再保护重复事件。若 DSH 在不同窗口提供不同的 `updatedAt`，也无法保证识别为同一次结束。
- IndexedDB 不可用时，降级为当前窗口内去重；多个窗口可能各自提醒，控制台会输出原因。过期记录在下次插件启动或事件处理时清理；旧版 localStorage 去重键在启动时移除。

## FAQ

### 没有 Discover，或搜索不到插件

先启用实验性 **Custom plugin indexes**，再添加索引；确认当前选中的索引源正确。索引管理中会显示加载错误。检查网络和 URL 是否能直接访问；CDN 更新可能有缓存延迟。

### 总开关开启，但没有系统横幅

先检查测试时是否有应用内卡片。如果卡片正常，依次检查：

1. 浏览器站点通知权限是否允许。拒绝后通常需在地址栏站点设置中修改，再刷新页面。
2. 系统是否允许浏览器或 DeepSeek Harness 显示通知，横幅样式是否启用。
3. 勿扰／专注模式、锁屏通知设置或企业策略是否拦截通知。
4. 是否处于支持 Notifications API 的安全上下文：优先使用 HTTPS；`localhost`／回环地址通常被视为可信本地来源，普通局域网 HTTP 地址不等同于 localhost。

桌面客户端显示已授权，也不代表操作系统一定展示横幅。浏览器支持情况见 [MDN Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API)。

### 拒绝权限后为什么还有应用内卡片

浏览器权限只管理系统通知。关闭 **完成通知总开关**才能停止所有插件提醒；只关闭 **提示音**则保留视觉提醒。

### 为什么没有声音

确认两个开关都开启，在页面内点击一次后发送测试通知。浏览器可能阻止未交互页面播放音频；检查标签页静音、系统音量及输出设备。音频受限不会阻止应用内卡片。

### 为什么重复提醒或漏提醒

先确认窗口是否共享同源存储；不同设备、浏览器或桌面端与网页端会分别通知。检查控制台是否提示 IndexedDB 不可用。清除本地数据会重置去重记录，完成事件还依赖 DSH 提供一致的标识。

短暂停顿后续跑、子代理及空白会话会被过滤；等待确认已有单独提醒。同源另一窗口可能已取得通知资格，本窗口便不会再弹卡片或播放声音。总开关关闭期间的事件不会在之后补发。

## 升级、回退与卸载

### 升级

在 Discover 中刷新索引，打开插件详情，检查新版本及兼容范围后安装。按 DSH 提示重新加载或重启，再发送测试通知。源码安装者更新 checkout 时应保留自己的未提交修改。

### 回退

在插件详情的版本列表中安装旧版（需索引保留该版本）。也可使用已核实的完整 commit：

```bash
dsh plugin --profile <profile> add 'git+https://github.com/Ly007-dotcom/dsh-turn-notify.git#<40位完整commit>'
```

替换占位符并重启对应 profile。回退会恢复该版本的行为和已知问题，旧版不一定使用新的去重存储格式。

### 停用、卸载和数据清理

在 Installed 中停用插件可停止监听，选择移除可卸载。CLI 等价操作为：

```bash
dsh plugin --profile <profile> remove dsh-turn-notify
```

CLI 操作后重启对应 profile。卸载通常不会清除浏览器／桌面存储分区中的偏好，也不会撤销站点通知权限。

若要只清理本插件数据，先在该分区所有窗口中停用插件并重新加载，释放数据库连接。再在开发者工具 Application／Storage 中删除：

- localStorage：`dsh-turn-notify:enabled`、`dsh-turn-notify:sound`、`dsh-turn-notify:prompt-dismissed`，以及旧版 `dsh-turn-notify:claim:` 前缀的键。
- IndexedDB：名为 **`dsh-turn-notify`** 的数据库，其中包含 `claims` 存储。

不要使用“清除全部站点数据”，以免删除其他 DSH 设置。数据库删除被阻塞时，关闭同分区其他窗口再重试；桌面分区须在桌面端自身的开发者工具中清理。清理后重新启用插件会恢复默认开启状态；浏览器权限需在站点设置中单独撤销。

## 隐私

插件本身不发起网络请求、不收集遥测、不上传会话内容。安装或更新时，DSH 会按索引访问 GitHub／CDN 等来源。

提醒标题来自会话标题；为空时使用工作目录最后一级名称，再为空则显示 `DSH`。正文为固定的“回合已结束”或“等待你的确认”，不包含对话正文。标题可能在锁屏、屏幕共享和系统通知历史中可见；如需避免显示，关闭插件通知或调整系统锁屏通知设置。

localStorage 保存开关和首次提示状态。IndexedDB 保存会话 ID、事件种类、请求 key 或更新时间组成的去重标识及到期时间，不保存标题、目录路径或对话正文。存储不可用时使用页面内存，关闭页面即丢失。操作系统可能独立保留已投递的通知。
